ARC Rocket Design Optimizer

Tech stack

Web app
Static site on GitHub PagesConditions form, job status and results; no server to run.
Sign-in
Firebase Auth with GoogleAllowlisted team accounts only.
Data
Cloud FirestoreCollections: jobs, rockets, flights, results, calibration. The only link between web app and worker.
Worker
Python process on a rented VM or a laptopPolls Firestore for jobs; no inbound ports.
Simulator
OpenRocket 24.12 (Java), driven by orlabPackaged with the optimizer in one container. RocketSim kept as a cross-check.
Optimizer
Grid or random sweep, Bayesian optimization or CMA-ES, Monte CarloSeeded and time-budgeted so results are reproducible.
AI parsing
Claude API, called from a parse functionCloud Function or worker job, still undecided. API key never reaches the browser.
Weather
Free forecast API, called from the browserPre-fills the conditions form; always editable.
Uploads
Altimeter CSVs parsed in the browserStored as numbers; no file storage in version 1.
